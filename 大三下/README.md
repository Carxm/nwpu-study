## 怎样使用

PDF 适合直接阅读；Word、Excel 和 LaTeX 文件便于继续记录或核对。Excel 打开后请重新计算，并留意说明中指出的固定数值和历史版本差异。个人复习内容和课程项目都不是官方答案或完整考试范围。

两个 HTML 页面需要下载后用浏览器打开。EV 展示请保留整个目录及 `assets/`，其中部分外部参考照片需要联网；Weibull 演示可以离线使用。GitHub 文件页显示源代码时，不代表网页损坏。Python 工具的安装、输入格式与运行示例见工具目录的 README。

小组共同材料已获同意分享，保留姓名、贡献及原有 AI 使用声明；公开副本移除了相关学号或签名。模拟数据、课程计算与实测记录在各自说明中区分。原资料中的数据矛盾不会通过悄悄修改原值来消除，已知差异见[复合材料数据核对说明](复合材料/实验记录/数据核对说明.md)和[LCA 版本说明](材料可持续性/硅胶烘焙模具LCA/README.md)。

课堂照片、教师课件、完整个人日志、重复过程稿和未整理的素材保留在原档案中。引用图表与外部素材仍归原权利人；使用这些文件时请保留来源，并独立完成自己的课程提交。
