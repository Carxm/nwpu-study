# 复合材料 QXU5030

本目录收录 Composite Materials 的复习清单，以英文问答为主，配有中文提示，包含 12 道复习题和 28 项术语速查，涵盖纤维与基体、铺层设计、加工工艺、混合律、短纤维载荷传递、界面失效及维修判断。

- [PDF 阅读版](复习list.pdf)：适合直接预览或打印。
- [Word 原文件](复习list.docx)：适合自行补充笔记，原文件内容和格式均保留。
- [实验记录与数据](实验记录/README.md)：两部分小组实验报告与原始工作表，含可定位的数据核对说明。

使用时建议先遮住答案，尝试用自己的话回答每道题，再对照关键词查漏补缺：Q1–Q4 梳理材料组成与选择，Q5–Q8 连接铺层、加工与缺陷，Q9–Q11 复习力学模型和失效机制，Q12 练习根据证据作出维修判断。遇到不熟悉的英文术语，可以先查文末词汇表，再回到对应章节；公式应同时记住假设和适用条件。

原文注明基于 Dr Shafique Ahmed 的课程幻灯片整理。本清单用于辅助复习，不代表完整考试范围或官方答案。文中的材料价格、性能数值和经验关系保留原笔记表述，使用时请结合相应材料、铺层和工况核对课程资料。本次保留 Word 原文件，并将相同内容排版为 PDF 阅读版，未逐条开展科学内容校订。
