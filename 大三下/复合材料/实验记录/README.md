# 复合材料实验记录

这里保留 wax composites 和 glass fibre/epoxy hand layup 两部分课程实验的报告与工作表，适合参考样品设计、实验记录和报告组织方式。**报告与工作表存在已知差异，尚不能作为一套已校准的数据直接复算；使用前请先读[数据核对说明](数据核对说明.md)。**

| 文件 | 内容 | 建议阅读方式 |
| --- | --- | --- |
| [实验报告 PDF](实验报告_阅读版.pdf) / [Word](实验报告_阅读版.docx) | 两部分实验的设计、方法、结果、讨论、参考文献、AI 使用声明与小组贡献 | 先看样品设计和测试方法，再把结果表与工作表逐项对照 |
| [蜡基复合材料工作表](data_all1.xlsx) | 样品尺寸、质量、断裂力及多轮计算记录 | `ex1` 的第 44–50 行与报告六个样品的原始量相对应；上方还保留了早期数据与探索计算 |
| [玻纤环氧层合板工作表](data_all2.xlsx) | 三种铺层的尺寸、载荷与尺子读数、挠度换算、刚度估算 | 先核对第 8 行的样品标签与支撑跨度；四层板分别有 4 cm、6.5 cm 两组测试记录 |

使用时先建立“样品编号—材料或铺层—试样尺寸—支撑跨度—载荷—位移”的对应关系，区分直接记录的测量值、计算结果与全尺寸设计假设。表中的数值缓存只是文件保存时的结果，不能代替在自己软件中的重算和条件核对。

这是小组课程实验资料，作者和贡献以报告末尾原始说明为准；其中共同数据已获同意分享。报告仅将一张浮动表格改为随正文排列，并调整该表题的分页，避免跨软件阅读时表格遮挡文字；正文、数据、公式、图片和贡献说明均保留。两个工作表按原文件收录，未为了使结果一致而改写测量值、实验条件或计算公式。报告中的课程设计条件不能直接作为实际航空构件的设计或认证依据。
