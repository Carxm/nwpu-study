# 陶瓷

本目录收录 2026 年 QXU6032 Advanced Ceramic and Glass Materials 的课程项目，以及用于理解 Weibull strength scatter 的交互演示和分析工具。

| 入口 | 内容 | 适合怎么用 |
| --- | --- | --- |
| [Weibull 交互演示](Weibull交互演示/README.md) | 单文件 HTML，调整 m、σ₀、示例点数和固定应力情景 | 先直观理解强度分散、分布形状与低强度尾部 |
| [Weibull 分析工具](Weibull分析工具/README.md) | Python 脚本、synthetic CSV 和示例输出 | 了解 specimen-level 数据怎样拟合与报告不确定性 |
| [课程项目](课程项目/README.md) | CW1 技术报告 45 页、CW2 展示 34 页 | 学习 ZTA 材料论证、文献使用与项目组织 |

项目是 Alumina5 小组共同成果，保留成员署名、贡献说明及原有 AI 使用声明，组员已同意共享。工具中的示例数据是明确标注的 synthetic data；HTML 使用固定课程案例值，不进行实时 FEA。相关概率和可靠性讨论用于课程学习，不能直接当作植入物临床失效率、寿命预测或材料合格结论。
