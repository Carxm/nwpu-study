# 硅胶烘焙模具 LCA 计算案例

这是一份 2026 年 Materials Sustainability 课程小组项目的计算案例，原文件为 `总_百分比修正版.xlsx`，小组已同意共享。归档保留原工作簿数值、公式、工作表与来源备注，不把课程模型结果当作实测产品认证结果。

## 从哪里开始

打开[计算工作簿](硅胶烘焙模具_LCA计算案例.xlsx)，先读 `Sources_Assumptions` 和 `LCI`，再看 `CO2`、`eco cost`，最后比较两种 improvement。不能运行表格软件时，可先看[结果快照](结果快照.csv)。

本版本的 functional unit 是一个硅胶烘焙模具提供 **300 次 baking cycles**；模具成品质量为 **0.340 kg**，包装质量 **0.060 kg**，运输总质量 **0.400 kg**，道路运输需求 **0.840 tonne-km**。基准情景采用冷水冲洗、自然晾干和填埋处理，未包含烤箱运行、洗碗机、清洁剂及热水清洗。比较结果只有在这些条件下才有意义。

## 工作簿记录的结果

| 情景 | CO₂ equivalent（kg / 300 次） | Eco-cost（€ / 300 次） | 与基准的变化 |
| --- | ---: | ---: | --- |
| Baseline | 3.691863 | 0.886518 | 基准 |
| Improvement 1 | 2.689357 | 0.582257 | CO₂ 下降约 27.2%；eco-cost 下降约 34.3% |
| Improvement 2 | 3.118445 | 0.962818 | CO₂ 下降约 15.5%；eco-cost 上升约 8.6% |

Improvement 1 在模型中减少 40% 的硅胶主体，并加入 0.030 kg secondary aluminium frame，还计入制造复杂性与废料率变化。Improvement 2 保留产品质量，以低碳电力、工艺与设备假设改变制造过程。表中数值来自本工作簿，不能直接推广到其他尺寸、寿命、清洗习惯或材料配方。

`CO2!G27`、`eco cost!G27`、`Improved CO2!G31`、`Improved Eco-cost!G31` 是前两种情景的计算结果。改进 2 的结果位于 `Improvement2 CO2!G28` 与 `Improvement2 Eco-cost!G29`，这些表中存在固定数值，修改输入不会让所有结果自动联动。`改进1放报告`、`改进2放报告` 也是写作快照，使用时应回查计算表。

## 使用边界与版本

这里选用的是 0.340 kg 计算版本。项目早期介绍稿采用过 0.20 kg 基准，另有以 0.335 kg 硅胶主体为输入的 openLCA 整理稿；这些材料不是本工作簿的配套说明，未混入本案例。这里不以文件名、修改时间或旧审计稿推定最终提交状态。

原工作簿含来源和 proxy 假设说明，但底层数据库、部分被引用的中间库存表和完整 openLCA 项目不随包提供。因此本目录适合学习 inventory、阶段贡献和方案比较，不能视作完整重现背景数据库计算的资料包。输入因子的出处、产品实测依据、耐久性不变假设、回收抵扣和其他模型选择仍需按研究用途进一步核实。

原文件的部分公式结果缓存为空。请用 Excel 或兼容表格软件打开并重新计算；纯文件预览可能显示空白。归档时独立读取并计算了 176 条现有公式，核对了本页总数及百分比，未改写原文件，也未重新运行 openLCA。CSV 是当前参数下的静态结果快照，输入变化后应重新导出。
