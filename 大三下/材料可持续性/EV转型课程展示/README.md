# Naples EV transition 课程展示

2026 年 Materials Sustainability individual coursework，作者为 Xuanming Che。主题是借鉴 Xi’an 的交通电动化经验，为 Naples 提出分阶段 EV transition 方案，展示内容包括 system map、priority map、implementation roadmap、causal loop、KPI 和 life cycle boundary。

## 打开与阅读

下载本目录后，用浏览器打开 [index.html](index.html)，保持 `assets/` 与 HTML 在同一目录。左右方向键或 Page Up / Page Down 翻页，Home / End 回到首页或末页。共 14 页，可配合[讲稿](讲稿.md)阅读。GitHub 文件页通常显示源代码，需下载后打开。

建议先看第 7 页 system map 和第 10 页 causal loop，再回看优先级、路线图与 KPI。它们展示了如何把治理、充电、车辆、公众支持和环境结果连接起来。

## 资料性质

这是历史课程作业与方案设计，保留作业当时引用的历史数据和政策语境。页面中的 2026–2035 roadmap、KPI、优先顺序与收益判断属于课程提出的方案或预期，不代表已获 Naples 政府采纳、已完成实施或已经验证的效果。关于 2035、现行政策、设施数量等信息，如用于新的研究或决策，应回到当前官方来源重新核对。

本次归档保留原展示结构、内容、图片署名和参考文献，只调整浏览器标题、补充课程归档提示、去除学号字段，并为网络照片加入离线提示。没有把历史数字改写为当前事实。
