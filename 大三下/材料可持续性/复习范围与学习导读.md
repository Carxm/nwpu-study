# Materials Sustainability 复习范围与学习导读

这份导读根据 2026 年课程复习照片中可辨认的主题重新整理，并借助 AI 辅助归纳。照片展示的是教师的课堂说明、练习题和 model answers；本页只提供知识范围和学习路径，不是本人当时独立完成的完整笔记，也不是教师发布的正式复习大纲。

## 知识主线

| 主题 | 复习时需要回答的问题 |
| --- | --- |
| Sustainability models | Environmental、social、economic dimensions 如何关联？Stool、house、concentric-circle 等模型分别表达什么结构与取舍？ |
| Systems thinking | 系统边界内有哪些相互依赖、feedback loops 和利益相关者？局部改善会不会把负担转移到其他阶段？ |
| Sustainable design | Eco-design、eco-efficiency、eco-effectiveness 与 biomimicry 分别从哪里介入产品设计？ |
| Life cycle assessment | 如何定义 functional unit 和 system boundary？BOM、inventory、impact factor 如何连接到全生命周期结果？Full LCA 与 streamlined LCA 的信息需求有何不同？ |
| Circular economy | Reuse、repair、take-back、recycling 如何改变材料循环？为什么技术可行不等于商业与社会层面能实施？ |
| Industrial ecology | 如何从物质流和能量流理解不同过程之间的关系，识别 waste 与 resource 的连接？ |
| Ethics and stakeholders | 如何识别 stakeholder 的 interest、influence、support 和 opposition？方案对不同群体及自然、人力和经济资本的影响是否一致？ |
| Policy and markets | 需要哪些协作机制、政策工具和激励？市场集中度、既有利益与转型阻力如何影响新方案？ |

## 两类案例如何练习

**产品生命周期计算。** 课堂复习用过家用电器情景，涉及材料清单、寿命、用电、排放和回收。练习时先写清功能服务与时间范围，再列出材料质量、能耗和处理比例的单位，逐阶段计算，最后比较改善方案。不要把一次使用、一个产品和整个寿命的结果混在一起。本仓库的[硅胶烘焙模具 LCA 案例](硅胶烘焙模具LCA/README.md)可用于练习同一思路，具体假设见其说明。

**转型方案判断。** 课堂复习还使用过消费品替代情景，要求依次明确目标、规模和时间，分析利益相关者，比较已知事实，再讨论环境、社会和经济影响。练习时可画一个小表，分开记录“已知数据”“假设”“预期收益”“可能受损群体”，使建议与证据对应。[EV 转型展示](EV转型课程展示/README.md)提供了更完整的 system map、causal loop 与 roadmap 示例。

## 建议阅读顺序

1. 先用自己的话解释 sustainability、system boundary 与 functional unit。
2. 练习把产品或转型情景拆成阶段、输入输出和利益相关者。
3. 完成一组带单位的 lifecycle 计算，核对分母、寿命和单位换算。
4. 比较方案时同时讨论收益、代价、数据缺口及适用条件。
5. 回到当年授课资料核对术语和教师强调的重点。
